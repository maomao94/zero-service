# IEC 104 采集数据采用三通道并行分发

ieccaller 将 IEC 104 采集数据同时通过 Kafka、MQTT、gRPC 三条通道并行推送，通道可独立启用：Kafka 面向大规模数采与多消费组场景，MQTT 面向物联网与自定义系统对接，gRPC 面向低延迟直连落库。stash/streamevent 消费链路以 Kafka 为主，MQTT 与 gRPC 服务外部系统。

选择三通道而非单一通道是因为下游消费者形态差异大（多消费组高吞吐、动态 Topic 物联接入、低延迟直连），单一通道无法同时满足；代价是三条推送路径与协议边界需要持续维护，且外部系统必须按自身场景选择消费通道。数据流与配置见 [IEC 104 数采平台](../iec104/iec104.md)。
