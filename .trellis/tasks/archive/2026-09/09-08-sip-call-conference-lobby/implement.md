# SIP 拨号会议大厅实施计划

## Checklist

- [x] 调整 `DialPad` 接收独立拨号后的会议进入回调。
- [x] 独立拨号成功且响应含会议号时调用现有入会流程；缺少会议号时显示明确错误。
- [x] 会议内拨号不触发切换，保持当前页面。
- [x] 将大厅测试电话改成紧凑 tag/短横向展开控件，保留供应商、号码、拨号和结果状态。
- [x] 加入桌面和移动端布局约束，避免控件溢出。
- [x] 运行前端构建并检查已有会议/供应商流程。

## Validation

```bash
npm run build
```

在 `web/live` 目录运行。真实 SIP 接通需要外部 LiveKit/SIP 环境，本任务只验证前端状态转换和构建。

## Risk And Rollback

- `DialPad` 可能同时用于大厅和会议管理面板；回调必须可选，避免改变会议内拨号行为。
- 自动进入会议必须复用根组件现有 `enterMeeting`，不在 DialPad 内重复获取 LiveKit token。
- 若布局改动影响供应商管理，回退 CSS/JSX 局部改动，不改变 API。
